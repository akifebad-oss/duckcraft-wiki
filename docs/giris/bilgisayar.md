# Bilgisayar (Java Edition) Giriş Rehberi

DuckCraft sunucusuna bilgisayar üzerinden katılmak isteyen oyuncular için hazırlanan bu rehberde, oyuna bağlantı adım adım anlatılmaktadır.

::: tip SUNUCU BİLGİLERİ
* **Sunucu Adresi (IP):** `mc.duckcraft.com.tr`
* **Sürüm:** 1.20.x (Önerilen En Güncel Java Sürümü)
* **Platform:** Minecraft Java Edition
:::

---

### Adım Adım Bağlantı Rehberi

1. **Minecraft Launcher'ı Başlatın**
   Bilgisayarınızdaki Minecraft Launcher uygulamasını açın ve hesabınıza giriş yapın. Profil bölümünden **Java Edition** seçeneğine tıklayın.

2. **Uygun Sürümü Seçin**
   Oyunu başlatmadan önce sürümünüzün 1.20 ve üzeri güncel bir Java sürümü olduğundan emin olun. Girişte sorun yaşamamak için önerilen sürümleri tercih edin.

3. **Çok Oyunculu (Multiplayer) Menüsüne Geçin**
   Oyun ana menüsü açıldığında **Çok Oyunculu** (Multiplayer) butonuna tıklayın.

4. **Sunucu Ekle Butonunu Kullanın**
   Sunucu listenizin alt kısmında yer alan **Sunucu Ekle** (Add Server) butonuna basın.

5. **DuckCraft IP Adresini Tanımlayın**
   Açılan pencerede gerekli alanları şu şekilde doldurun:
   * **Sunucu Adı:** `DuckCraft`
   * **Sunucu Adresi:** `mc.duckcraft.com.tr`

6. **Kaydedin ve Bağlanın**
   **Tamamlandı** (Done) butonuna basarak sunucuyu listenize ekleyin. Liste üzerinde DuckCraft logosunu gördükten sonra çift tıklayarak veya **Sunucuya Katıl** butonuna basarak giriş yapın.

---

### Giriş Yaparken Dikkat Edilmesi Gerekenler

* Sunucu adresini (`mc.duckcraft.com.tr`) yazarken başında veya sonunda boşluk bırakmadığınızdan emin olun.
* Bağlantı stabilitesi için kablolu internet bağlantısı veya güçlü bir Wi-Fi sinyali önerilir.
* İlk kez giriş yapıyorsanız hesabınızı koruma altına almak için şifre belirleme ekranındaki yönlendirmeleri takip edin.

---

### Sık Karşılaşılan Sorunlar ve Çözümleri

::: details Sunucuya bağlanamıyorum / "Can't connect to server" hatası alıyorum
* Sunucu adresini yanlış yazmış olabilirsiniz. `mc.duckcraft.com.tr` adresini kontrol edin.
* İnternet bağlantınızı veya güvenlik duvarı ayarlarınızı kontrol edin.
:::

::: details "Outdated Server" veya "Invalid Session" Hatası
* Minecraft sürümünüz sunucu ile uyumsuz olabilir. Sürümünüzü 1.20 ve üzeri bir sürüme güncelleyip launcher'ı yeniden başlatın.
:::
